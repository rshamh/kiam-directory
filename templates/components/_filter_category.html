{% comment %} One speciality category in the sidebar: a collapsed row that opens onto its own specialities. {% include "components/_filter_category.html" with category=category params=params %} Params: category (from `facets_with_counts`) · params Alpine does three things here and each of them degrades to nothing: * `x-show` hides the whole category when the filter box has text that matches neither its name nor any speciality inside it. `haystack` is built and lower-cased once in `facets_with_counts`, not joined per keystroke in the browser. * `:open` opens a matching category while the box has text, and hands control back to `was` — the visitor's own state — the moment it is cleared. * `@toggle` records that state, guarded by `if (!q)`. Without the guard, Alpine's own opening of a matching category is recorded as if the visitor had done it, and clearing the box leaves all eighteen open. With script off, none of the attributes do anything: the category renders with whatever `open` the server decided, which is "open when it holds a selection". {% endcomment %}
