{% comment %} 500 — deliberately self-contained. This does NOT extend base.html, and that is the point. A 500 can be caused by the database being down, by Redis being down, or by a context processor raising — and kiam-ui's chrome needs the `kiam_ui` and `a11y` context processors plus a static manifest lookup to render at all. A 500 page that needs any of those fails while rendering, and Django falls back to a bare "A server error occurred", which is what visitors would actually see exactly when things are worst. So: no {% templatetag openblock %} extends {% templatetag closeblock %}, no {% templatetag openblock %} static {% templatetag closeblock %}, no context variables. Inline styles only, using the same brand values kiam-ui defines — this is the one place in the repo permitted to restate them, because it cannot rely on the stylesheet having loaded.
